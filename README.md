# Waterle

Is it tap water or mineral water? Guess. You have a 50% chance.

Live at https://sugoijan.dev/waterle/

A single static `index.html`, deployed to GitHub Pages on every push to `main`.

## Photos

The glasses in `img/` are from [Unsplash](https://unsplash.com) under the
[Unsplash License](https://unsplash.com/license). `img/CREDITS.txt` maps each
file to its original Unsplash photo. Originals live in `originals/` (not
committed); `./resize.sh` regenerates the web-sized crops.
